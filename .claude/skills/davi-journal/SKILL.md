# davi-journal — 팀 개발일지

발표·회고용 팀 일지를 **davi 저장소의 형제 폴더** `..\davi-journal`(조직 프라이빗 레포
`flyai-kfc/davi-journal`의 클론 — 각자 워크스페이스에서 davi 옆)에 남긴다.
**davi 모노레포에는 일지 본문을 쓰지 않는다** — 여기 있는 건 스킬 코드뿐이다.
아래 경로는 전부 davi 저장소 루트 기준이다. 클론이 없으면 먼저:

```powershell
gh repo clone flyai-kfc/davi-journal ..\davi-journal
```

## 언제 쓰나 — 문턱이 높다

- **발표에서 언급할 만한 것만**: 방향 전환, 아키텍처·계약 결정, 실측으로 뒤집힌 가정,
  데모에 쓸 성과.
- **기록 여부는 에이전트가 스스로 판단한다.** 사용자가 "발표감이다", "일지 남겨라"라고
  말해주길 기다리면 이 스킬은 무의미하다. 기록 시점은 둘이다 — ① 위 범주의 마일스톤이
  세션 중 **확정되는 순간**(설계 확정, 실기기 검증 통과, PR 머지 등) ② 이미 확정된
  마일스톤 소식을 접했는데 **일지에 아직 없을 때**. 그 턴에 바로 기록하고 한 줄로 알린다.
- **중복 확인**: 쓰기 전에 `journal/`의 최근 파일들에서 같은 마일스톤이 이미 있는지 확인한다.
  있으면 쓰지 않는다(새 사실이 추가된 경우만 기존 항목 아래에 보강).
- 쓰지 않는 것: 사소한 결정, 개인 학습·삽질(각자의 개인 저널로), 아직 결론 안 난 논의.
- 개인 저널과 문턱을 둘 다 넘는 마일스톤이면 **양쪽에 기록한다** — 대상 독자와 목적이
  달라 중복이 아니다.

## 어떻게 쓰나

1. 작업자 로그인 확인: `gh api user -q .login` (실패 시 `git config user.name`)
2. 오늘 로컬 날짜의 `..\davi-journal\journal\YYYY-MM-DD.md`가 없으면 아래 형식으로 생성,
   있으면 **맨 아래에 어펜드**:

```markdown
---
date: 2026-07-29
authors: [GunderGie]
---

## <제목> `@GunderGie`

**배경** — 어쩌다 이 문제를 만졌나 (한두 문장)

**결정** — 핵심 내용 (성격에 따라 **배운 것** / **함정** / **성과**)

**왜 / 버린 대안** — 근거와 기각한 선택지

**증거** — 실측·로그·수치 요약

**연결** — 이슈·PR·파일
```

3. **작업자 태그는 필수다** — 항목 제목 뒤 `` `@<login>` ``, frontmatter `authors:` 목록에
   없으면 추가. 해당 없는 본문 필드는 생략한다.
4. 커밋 → pull → 푸시. **이번에 쓴 일지 파일만 pathspec으로 stage한다** — `add -A`는 저장소에
   남아 있던 무관한 변경(사용자 초안 등)까지 자동 전송한다(PR #65 리뷰 P1). `status`에 무관한
   변경이 보여도 건드리지 말고 그대로 둔다. **pull은 커밋 뒤에** 한다(쓰기 전에 하면 미커밋
   변경과 충돌한다):

```powershell
git -C ..\davi-journal status --short
git -C ..\davi-journal add journal/<YYYY-MM-DD>.md
git -C ..\davi-journal commit -m "journal: <날짜> <제목>"
git -C ..\davi-journal pull --rebase
git -C ..\davi-journal push
```

rebase가 충돌하면 자동으로 풀지 않는다 — `git rebase --abort`로 되돌리고 커밋만 남긴 채
사용자에게 알린다(자동 실행 경로의 임의 병합은 위험하다). 푸시 실패(권한·오프라인)도
커밋만 남기고 알린다.

5. 기록 후 사용자에게 **한 줄로** 무엇을 남겼는지 알린다.

## 문체

한국어, 구조화 항목형(위 필드). 읽기 좋게 다듬는 건 발표 준비 단계의 일이다 — 여기서는
맥락 밀도가 우선. 과장 없이, 코드 식별자는 영어 그대로.

API 키·토큰·개인정보·마스킹 전 화면 내용. 쓰기 전에 한 번 훑는다.
